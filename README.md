# iTunes Search App

## Description

This full-stack application allows user to search the iTunes Store using the iTunes Search API.

Users can:

- Search for media content
- Filter by media type
- Add items to favourites
- Remove items from favourites

The favourites list is only stored while the application is running.

## Technologies

### Frontend

- React
- Vite
- Bootstrap

### Backend

- Node.js
- Express
- JWT

## Installation

Install frontend dependencies:

```bash
npm i
```

Install backend dependencies:

```bash
cd server
npm i
```

## Run the Application

Start the backend:

```bash
cd server
npm start
```

Start the frontend:

```bash
npm run dev
```
